# 常见问题

## 安装与启动

**左侧没有「砚田」入口。**
先确认是完全退出 Harness 后重新打开的（刷新页面不够，插件含宿主侧代码）。再检查 `设置 → 插件` 里 `dsh-yanfield` 是否启用、版本是否为刚安装的那次；`砚田 → 设置 → 关于 → 构建` 会显示这个包是什么时候构建的。

**装完报版本不兼容。**
插件要求 Harness `>=0.2.1-rc.5 <0.3.0`。升级或回退 Harness 后再安装。

**能打开界面，但模型用不了。**
见下面「模型与余额」。

**怎么卸载。**
`dsh plugin --profile <profile> remove dsh-yanfield`，然后重启 Harness。书稿不会被删除。

## 模型与余额

**报 `no API key for provider route "deepseek-official"`。**
当前模型路由是「官方 API Key」，但没有可用 Key。到 `砚田 → 设置 → 模型服务` 把路由切到「DeepSeek 账号登录」，或在 Harness 的模型服务页填 `DEEPSEEK_API_KEY`。插件默认优先账号路由，只有你手动切过去才会用到 Key 路由。

**模型选择器里没有 `deepseek-v4-pro`。**
打开一次 `设置 → 模型服务` 会触发目录同步；如果仍没有，说明当前 Harness 侧的 DeepSeek 适配器只公布了一个模型，可以手动填模型 ID。

**余额显示「—」或提示未登录。**
余额查的是 Harness 里已登录的 DeepSeek 账号。先去 Harness 登录，再点「查询余额」。

**余额和 DeepSeek 官网不一致。**
以 DeepSeek 官方为准；插件读到的是账号服务的返回值，可能有延迟或口径差异（例如赠送额度、代金券）。

## 费用

**一直显示「费用未知」。**
两种情况：接口没有返回 usage（例如中断、失败），或者模型不在内置价目表里且没有配置单价。到 `设置 → AI 与上下文 → 用量与费用` 填三档单价即可显示预估。

**数字看着很大。**
底栏数字是**今日累计** token 与费用，不是单次任务。点开可以看到每条消息的明细；单次任务的费用通常只有几分钱到一毛。

**预估和账单差很多。**
预估值基于本地单价与 usage 估算，缓存命中、官方调价、未上报 usage 都会造成差异；以 DeepSeek 账单为准。

**Q：上下文预算默认多少？会不会把长篇撑爆？**
默认不设上限——DeepSeek 的窗口是 1,048,576 tokens，足够带上大纲、资料和大量前文。真要限制成本，可以在「设置 → AI 与上下文」选 96k / 128k / 256k / 512k。任务进行中若上下文真的逼近窗口，会先丢弃最旧的观察记录；仍超窗口时会明确提示「预计需要 X tokens，超过窗口 Y」，不会静默截断。

**Q：快到 1M 上限时会自动压缩（compact）历史吗？**
目前没有「语义摘要式压缩」。超预算时的处理是：聊天历史按最近 N 条 + 总字符上限保留、更早的丢弃并在 system prompt 里标注「更早的对话已省略」；任务中的观察记录按预算从最旧的开始裁剪。真到窗口上限会报错而不是悄悄丢内容。需要自动摘要压缩的话可以再加（每次压缩要多花一次模型调用的钱），现阶段默认不做。

## 写作与资料

**AI 看不到某个设定。**
设定默认在「揭示章节」之前对 AI 隐藏；另外每张卡有「AI 可见性」开关，关掉后即使 `@` 引用也读不到。

**AI 改完的正文没变。**
改动是候选状态，需要在正文区逐段「保留」后点「确认审阅结果」；未决定的段落按原文处理。也可以直接「全部还原」。

**应用之后想撤销。**
任务卡上有「撤回本轮」；也可以在 `查看历史改动` 里找历史快照。

**示例作品能删吗。**
可以。书架卡片「…」菜单里删除；`设置 → 数据` 里也能重新生成示例作品（会覆盖同名示例书稿）。

**导入 TXT 后章节不对。**
导入按「第 N 章」「第 N 卷」等标题行拆分，导入前会显示预览；标题格式不统一时可以先整理文本，或导入后用章节目录手动调整。

## 数据

**书稿存在哪。**
默认 `$DSH_HOME/yanfield/yanfield.db`（另有 `-wal`、`-shm`）。`设置 → 数据` 显示实际路径并可打开文件夹。也可以用 `YANFIELD_DB_PATH` 或插件配置的 `dataDir` 指定。

**怎么备份 / 换电脑。**
退出 Harness 后复制整个数据库目录；换电脑时保持路径不变即可，或在新机器上用 `YANFIELD_DB_PATH` 指向拷贝后的文件。

**数据会上传吗。**
不会。只有你主动发起 AI 请求时，相关上下文才会发送给你选择的 DeepSeek 服务；插件本身不采集遥测。

## 界面

**弹窗位置偏了 / 遮罩盖住了 Harness 侧栏。**
这是旧版本的问题，已在当前版本修好。若仍出现，确认安装的是最新构建（看「设置 → 关于 → 构建」时间）。

**主题不跟随 Harness 切换。**
插件监听 Harness 的明暗标记；如果 Harness 本身没有切换标记，可以在 `设置 → 外观` 里手动选宣纸 / 夜航 / 跟随系统。

**界面文字太小 / 太淡。**
`设置 → 编辑器` 可以调整正文字号、行高、页边距；浅色主题的辅助文字在 0.1.1 之后提高了对比度，如果仍觉得淡，可以截图反馈。
