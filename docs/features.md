# 功能说明

这份文档把砚田插件里能用的东西按模块列全，方便查漏。界面语言为中文。

## 一、书架

- 作品卡片：封面底色（墨夜 / 朱砂 / 黛青 / 鎏金 / 夜航 / 远山 / 青竹 / 天青）、状态（草稿 / 连载中 / 完结）、类型、卷章数、字数、最近更新时间。
- 新建作品：书名、类型、一句话简介、封面底色、作品简介、可选初始卷。
- 搜索（书名 / 简介）、按类型筛选、按最近更新或字数排序。
- 「示例作品」按钮会生成一份示例书稿，用于快速体验。
- 卡片右上角「…」：重命名、改状态、复制简介、删除（删除前有确认）。

## 二、作品概览

- 头部：作品名、类型、状态、写作入口。
- 统计卡：总字数、卷数、章数、今日字数、档案覆盖率。
- 「继续写作」入口：回到最近编辑的章节。
- 卷进度、最近章节列表。
- 写作目标：目标字数、每日字数、完成度。
- 故事档案摘要：最新档案、待更新、待提取。

## 三、写作台

三栏布局：

- **左栏**：目录（卷 / 章树）、章纲、设定（角色 / 地点 / 世界观 / 伏笔）、档案。窄屏时左栏收进抽屉。章纲、设定和档案可在浮窗中参照，切换左栏页签时仍可边看边写。拖标题栏移动，拖右下角缩放，也可一键放大、还原或最小化。长文随内容展开，在窗口内连续阅读和编辑。
- **设定排序**：拖动卡片右侧的手柄，或聚焦手柄后按上、下方向键。同组同父级的顺序按作品保存，子卡跟随父卡移动。清空搜索即可调整顺序。
- **中间**：正文编辑器（Tiptap）。顶部工具栏含撤销/重做、标题层级、加粗/斜体/下划线/删除线、引用、列表、分隔线、格式工具栏与「AI 助手」下拉菜单。
- **右栏**：AI 助手面板（见第六节）。

写作相关能力：

- 自动保存（延迟可在设置里调，默认 1.2 秒）与手动保存按钮；保存状态在顶部显示。
- 字数 / 段落 / 阅读时间统计；章节状态（草稿 / 定稿等）。
- 专注模式（隐藏左右栏）、打字机模式（光标保持视口中部）。
- 排版可调：正文字体（衬线 / 黑体）、字号、字重、行高、字间距、段落间距、页边距、最大行宽；右侧有实时预览。
- 正文查找和替换。按 `Ctrl / ⌘ + F` 在正文区右下角打开面板，格式工具栏留在原位。输入关键词时原位高亮，用上一个或下一个跳转。替换后可用 `Ctrl / ⌘ + Z` 撤销并回到改动位置。
- 格式工具栏随正文滚动固定在编辑区顶部。`Alt + 1` 收起 / 展开目录，`Alt + J` 聚焦 AI 输入框。
- 在 macOS 版 Harness 的窗口模式下，拖动写作台顶栏的空白处可以移动窗口。
- 在写作台内切回读过的章节，会恢复该章的光标和滚动位置。切章后开始新的撤销历史。

## 四、资料系统

- **大纲**：总纲（作品级）、卷纲、章纲。章纲字段：目标、冲突、情感线、场景节拍、剧情点、钩子、目标字数、悬念和转折强度。
- **角色卡**：姓名、别名、身份、年龄、性格、目标、关系、外貌、秘密、出场章节、AI 可见性。
- **地点卡**：名称、别名、地点类型、上级地点、感官细节和布局。可按地点层级浏览，并设置 AI 可见性和揭示章节。
- **世界观**：名称、类别、重要程度、描述、关联角色、揭示章节、AI 可见性。
- **伏笔**：内容、埋设章节、回收章节、状态、重要程度。
- **故事档案**：本章摘要、人物状态、设定变动、总账、时间线、待确认冲突；正文改动后标记过期，重新提取时保留人工校订内容。
- **可见性规则**：设定在「揭示章节」之前默认对 AI 隐藏；关闭「AI 可见性」后，即使 `@` 引用也读不到。

## 五、导入导出

- **导入 TXT**：识别「第 N 章」「第 N 卷」等标题自动拆章，预览确认后写入；单次上限约 2000 章。
- **导出**：整部作品或单章导出 Markdown / TXT。
- **备份**：设置 → 数据里可打开数据库所在文件夹，或复制路径。

## 六、AI 助手

面板结构：

- 顶部：会话标题（首条提问自动命名）、历史会话、新对话。
- 询问助手对作品的看法时，它可以先读相关资料，再直接给出答复。执行过程和已读资料可展开查看。
- 助手保留已显示的进度说明，答复接在下方逐步显示。需要审阅的候选在答复显示完后出现。
- 在正文审阅中应用改动后，聊天卡片会同步显示已应用状态。打开「执行记录」可查看各工具的结果和引用资料。
- 同一部作品内切换章节时保留当前会话。新发送的消息以当前章节为上下文，已发出的任务继续使用发送时指定的章节。
- 每次发送时先判断这轮要交付的内容，再开放对应工具。可以从正文整理设定卡而不改稿。同一轮需要修改多类内容时，可以一起明确提出。使用「继续修改」可指定要接着改的待审候选。
- 正文工具栏的「续写」「扩写」「润色」和「去 AI 味」快捷任务会在正文生成阶段使用相应的启用预设。提示词预设提供写作要求，改动范围由本轮请求决定。
- 批量建卡或改卡使用同一次资料操作。每项独立校验，有问题的条目会在执行记录里显示，已生成的候选仍可在当前回复下审阅。
- 从历史会话重试任务时，会使用任务原来的章节。新版生成的任务也会恢复选区、引用与上下文设置。
- 发送带选区的消息时，气泡上会显示章节和正文行号。展开引用可查看发送时的原文。行号按段落和手动换行计算。
- 选中正文后说「这里顺一点」即可润色选区。「接着写」会续在当前章末尾。「根据正文改章纲」会先读完整章，再准备当前章的章纲候选。
- 点击 AI 输入框后，引用中的正文仍以较淡的底色标出。回到正文放下光标即可取消选区，重新选择则会更新引用。
- 中部：消息流。AI 任务的执行过程按顺序保留，当前步骤原地更新；上翻阅读时暂停自动滚动。
- 底部：技能（快捷指令）、智能体 / 文风 / 档案选择器、输入框、模型与思考档位、`@` 引用、发送。
- 输入框底部状态行：今日用量、预估费用、余额。

能做什么：

- 续写、扩写、润色、去 AI 味、章节诊断、章纲、角色卡、世界观卡、故事档案提取。
- 修改正文（逐段审阅）、修改设定（按字段对比）、新建资料卡、整理章纲、伏笔登记。
- `@` 引用章节 / 角色 / 地点 / 设定 / 伏笔 / 档案；上下文预算（默认不限，可选 96k / 128k / 256k / 512k）与分节预览。
- 写作快捷任务与编辑面板提供对应的默认提示词，可在设置中按需自定义。
- 智能体人设：名称、职责、人设说明、问候语、额外要求，可恢复默认。

审阅流程：

1. 正文候选显示字数变化（如 `319 → 338 字（+19）`）。资料候选默认只显示可点击的名称，点开一项可查看字段差异、原文依据，并应用或丢弃该项。用名称旁的复选框选择需要批量应用的资料。工具和读取记录可从「执行记录」打开。
2. 正文区同时打开「审阅修订」：原文（删除内容红色划线）与修订稿（新增内容绿色高亮）并排。
3. 每段可点「保留」或「还原」；也可以「全部还原」「全部保留」。
4. 点「确认审阅结果」后，只把保留的段落写入正文；未决定的段落按原文处理。
5. 应用后可以「撤回本轮」，或「查看历史改动」。

带选区的正文改写仅替换当前章的选中文字。也可以引用能唯一定位的原句来指定局部修改，其余正文和格式会保留。明确要求从本轮改稿提取的资料默认不勾选，每个补充字段都有对应的原文引文。已保存正文包含引文时，可单独应用资料。引文只出现在候选里时，先保留相关段落，或和资料一起应用。性格、说话风格和长期目标可通过单独的资料修改请求整理。

## 七、设置

- **模型服务**：添加 / 编辑 / 启用 / 删除服务；模型路由切换（DSH 账号登录 / 官方 API Key）；查询余额；默认模型；手动或自动同步模型列表。
- **提示词预设**：默认打开自定义预设。可查看或复制内置模板，管理自己为特定快捷任务或编辑面板编写的模板。
- **智能体**：人设与超时等参数。
- **AI 与上下文**：上下文组成开关、上下文预算、单次输出上限、用量与费用（三档单价、官方单价一键填入、今日/累计统计）、自定义指令。
- **编辑器**：字体、字号、行高、字间距、段落间距、页边距、最大行宽与实时预览。
- **外观**：主题（宣纸 / 夜航 / 跟随系统）、自动保存、打字机模式、专注模式、自动保存延迟、每日字数目标。
- **数据**：数据库路径、打开所在文件夹、复制路径、导出全部作品、导入 TXT、危险区（重新生成示例作品等）。
- **关于**：版本、仓库、文档、问题反馈、构建时间、许可证、技术栈、致谢。

## 八、快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Alt + 1` | 收起 / 展开目录 |
| `Alt + J` | 聚焦 AI 输入框 |
| `Ctrl / ⌘ + K` | 快速跳转（章节 / 角色 / 设定 / 档案 / 页签） |
| `Ctrl / ⌘ + F` | 页内查找 |
| `Enter` | 发送 AI 消息 |
| `Shift + Enter` | AI 输入框内换行 |
| `Esc` | 关闭浮层 / 退出沉浸 |

## 九、已知限制

- 只适配 DeepSeek 官方接口与 Harness 已配置的 DeepSeek 服务，不支持第三方网关。
- 离线演示模式只提供模板文本，不能真正执行多步改稿。
- 一次 AI 任务最多 12 轮决策；复杂的多章任务可能需要分几次做。
- 费用为估算值，与实际账单可能有差异（缓存命中、未上报 usage 等）。
