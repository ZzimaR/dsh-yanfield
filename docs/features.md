# 功能说明

这份文档把砚田插件里能用的东西按模块列全，方便查漏。界面语言为中文。

## 一、书架

- 作品卡片：封面底色（墨夜 / 朱砂 / 黛青 / 鎏金 / 夜航 / 远山 / 青竹 / 天青）、状态（草稿 / 连载中 / 完结）、类型、卷章数、字数、最近更新时间。
- 新建作品：书名、类型、一句话简介、封面底色、作品简介、可选初始卷。
- 搜索（书名 / 简介）、按类型筛选、按最近更新或字数排序。
- 「示例作品」按钮会生成一份示例书稿，用于快速体验。
- 卡片右上角「…」：重命名、改状态、复制简介、删除（删除前有确认）。

## 二、作品概览

- 头部：作品名、类型、状态、写作入口。
- 统计卡：总字数、卷数、章数、今日字数、档案覆盖率。
- 「继续写作」入口：回到最近编辑的章节。
- 卷进度、最近章节列表。
- 写作目标：目标字数、每日字数、完成度。
- 故事档案摘要：最新档案、待更新、待提取。

## 三、写作台

三栏布局：

- **左栏**：目录（卷 / 章树）、章纲、设定（角色 / 世界观 / 伏笔）、档案。四个页签都支持就地浮窗编辑，不离开正文。
- **中间**：正文编辑器（Tiptap）。顶部工具栏含撤销/重做、标题层级、加粗/斜体/下划线/删除线、引用、列表、分隔线、格式工具栏与「AI 助手」下拉菜单。
- **右栏**：AI 助手面板（见第六节）。

写作相关能力：

- 自动保存（延迟可在设置里调，默认 1.2 秒）与手动保存按钮；保存状态在顶部显示。
- 字数 / 段落 / 阅读时间统计；章节状态（草稿 / 定稿等）。
- 专注模式（隐藏左右栏）、打字机模式（光标保持视口中部）。
- 排版可调：正文字体（衬线 / 黑体）、字号、字重、行高、字间距、段落间距、页边距、最大行宽；右侧有实时预览。
- 正文查找；`Alt + 1` 收起 / 展开目录；`Alt + J` 聚焦 AI 输入框。

## 四、资料系统

- **大纲**：总纲（作品级）、卷纲、章纲。章纲字段：目标、冲突、情感线、场景节拍、剧情点、钩子、目标字数。
- **角色卡**：姓名、别名、身份、年龄、性格、目标、关系、外貌、秘密、出场章节、AI 可见性。
- **世界观**：名称、类别、重要程度、描述、关联角色、揭示章节、AI 可见性。
- **伏笔**：内容、埋设章节、回收章节、状态、重要程度。
- **故事档案**：本章摘要、人物状态、设定变动、总账、时间线、待确认冲突；正文改动后标记过期，重新提取时保留人工校订内容。
- **可见性规则**：设定在「揭示章节」之前默认对 AI 隐藏；关闭「AI 可见性」后，即使 `@` 引用也读不到。

## 五、导入导出

- **导入 TXT**：识别「第 N 章」「第 N 卷」等标题自动拆章，预览确认后写入；单次上限约 2000 章。
- **导出**：整部作品或单章导出 Markdown / TXT。
- **备份**：设置 → 数据里可打开数据库所在文件夹，或复制路径。

## 六、AI 助手

面板结构：

- 顶部：会话标题（首条提问自动命名）、历史会话、新对话。
- 中部：消息流。AI 任务的执行过程按顺序保留，当前步骤原地更新；上翻阅读时暂停自动滚动。
- 底部：技能（快捷指令）、智能体 / 文风 / 档案选择器、输入框、模型与思考档位、`@` 引用、发送。
- 输入框底部状态行：今日用量、预估费用、余额。

能做什么：

- 续写、扩写、润色、去 AI 味、章节诊断、章纲、角色卡、世界观卡、故事档案提取。
- 修改正文（逐段审阅）、修改设定（按字段对比）、新建资料卡、整理章纲、伏笔登记。
- `@` 引用章节 / 角色 / 设定 / 伏笔 / 档案；上下文预算（4k–96k 或不限）与分节预览。
- 提示词预设：内置 20 条，可新建、编辑、停用、恢复默认。
- 智能体人设：名称、职责、人设说明、问候语、额外要求，可恢复默认。

审阅流程：

1. AI 提出改动后，任务卡里常驻列出全部候选：正文改动带字数变化（如 `319 → 338 字（+19）`），资料改动直接展开字段级「原 / 改」对比；执行过程与读取记录才折叠，调试详情只在出错时出现。
2. 正文区同时打开「审阅修订」：原文（删除内容红色划线）与修订稿（新增内容绿色高亮）并排。
3. 每段可点「保留」或「还原」；也可以「全部还原」「全部保留」。
4. 点「确认审阅结果」后，只把保留的段落写入正文；未决定的段落按原文处理。
5. 应用后可以「撤回本轮」，或「查看历史改动」。

## 七、设置

- **模型服务**：添加 / 编辑 / 启用 / 删除服务；模型路由切换（DSH 账号登录 / 官方 API Key）；查询余额；默认模型；手动或自动同步模型列表。
- **提示词预设**：内置与自定义预设的增删改、启停、恢复默认。
- **智能体**：人设与超时等参数。
- **AI 与上下文**：上下文组成开关、上下文预算、单次输出上限、用量与费用（三档单价、官方单价一键填入、今日/累计统计）、自定义指令。
- **编辑器**：字体、字号、行高、字间距、段落间距、页边距、最大行宽与实时预览。
- **外观**：主题（宣纸 / 夜航 / 跟随系统）、自动保存、打字机模式、专注模式、自动保存延迟、每日字数目标。
- **数据**：数据库路径、打开所在文件夹、复制路径、导出全部作品、导入 TXT、危险区（重新生成示例作品等）。
- **关于**：版本、仓库、文档、问题反馈、构建时间、许可证、技术栈、致谢。

## 八、快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Alt + 1` | 收起 / 展开目录 |
| `Alt + J` | 聚焦 AI 输入框 |
| `Ctrl / ⌘ + K` | 快速跳转（章节 / 角色 / 设定 / 档案 / 页签） |
| `Ctrl / ⌘ + F` | 页内查找 |
| `Enter` | 发送 AI 消息 |
| `Shift + Enter` | AI 输入框内换行 |
| `Esc` | 关闭浮层 / 退出沉浸 |

## 九、已知限制

- 只适配 DeepSeek 官方接口与 Harness 已配置的 DeepSeek 服务，不支持第三方网关。
- 离线演示模式只提供模板文本，不能真正执行多步改稿。
- 一次 AI 任务最多 12 轮决策；复杂的多章任务可能需要分几次做。
- 费用为估算值，与实际账单可能有差异（缓存命中、未上报 usage 等）。
